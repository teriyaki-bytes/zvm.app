## Why Zig needs a version manager

Zig is still pre-1.0. The standard library is under heavy development and the
roadmap is long, so releases regularly break existing builds, change valid
syntax, and add features like the package manager. That's great for the
language, but it means you often need several versions installed to build
different projects.

Staying on the master branch means downloading Zig often. You could find the
right archive for your platform, unpack it, and put it on your `$PATH` by hand
each time. Or you could run `zvm i master`.

ZVM is a static binary under a permissive license with no system dependencies.
It supports more platforms than any other Zig version manager: Windows, macOS,
Linux, the BSDs, and Plan 9.
